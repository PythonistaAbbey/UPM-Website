# User Journeys

Current-state steps are based on the audited public pages (sources in `SOURCE_REGISTER.md`). Future-state steps describe the prototype. "Implemented" means the journey can be walked through in this repository today.

| # | Audience | Goal | Current journey (observed) | Pain points | Prototype journey | Status |
|---|---|---|---|---|---|---|
| 1 | Prospective undergraduate (Malaysian) | Find a programme and how to apply | Home → Admission → Programmes → Undergraduate: one long list, no links (S06); separate How to Apply page with tabs (S08) | No detail pages, no filters, inconsistent channel naming | Home hero search → filtered catalogue → programme page → "See application routes" → UPU link | Implemented |
| 2 | Prospective postgraduate | Find a research degree and contact admissions | spel Postgraduate page (S07) → sgs.upm.edu.my (S15) → prospective students page (failed to load in audit, S16) | Conflicting counts; content split across two sites | Study → Programmes filtered to Postgraduate → detail → SGS contacts in directory | Implemented (coursework list missing) |
| 3 | Current undergraduate | Reach the student portal or learning platform | Sitemap "online services" list of 11 links, several http:// (S04) | Hard to find, no descriptions | Utility bar → Student services → grouped links with login and http warnings | Implemented |
| 4 | Current postgraduate | Check semester dates, submit an extension form | sgs homepage calendar text (S15); form via student portal | Calendar buried in homepage | Student services → Academic calendars / Postgraduate studies; news archive shows dated calendar event | Implemented |
| 5 | International student | Understand visa and arrival steps | Admission → Visa & Pass: empty page (S14); i-PUTRA homepage last news 2019 (S19) | No guidance | International hub → clear notice that verified guidance is missing, link to i-PUTRA, enquiry routed to international office | Implemented (content gap made visible) |
| 6 | Academic staff | Claims, email, HR systems | Sitemap online services; iDEC page (S04, S26) | Scattered, http links | Utility bar → Staff services → grouped by task | Implemented |
| 7 | Administrative staff | Find a policy | Quick link "Dasar UPM" to pnc site (S04) | One unlabelled link | Staff services → University policies | Implemented (link only) |
| 8 | Researcher / industry | Find expertise or commercialisation help | RMC, Science Park, AI Hub as separate sites (S24, S25, S28) | No cross-unit researcher search | Research → Find researchers and projects (demo) → Putra Science Park services | Implemented with demo data |
| 9 | Alumni | Update details, find events | alumni.upm.edu.my (S22) | Separate site | Alumni & Partners → Alumni Relations Centre | Implemented (link out) |
| 10 | Industry / community partner | Start a collaboration | Entity list → CIRNET / UCTC (S05) | Must know unit names | Alumni & Partners → partner routes; enquiry topic "Research and industry" | Implemented |
| 11 | Parent / visitor | Find a building and a contact | Contact page: address, phone, no map (S12) | No map | Campus map (schematic) + directory search | Implemented (positions illustrative) |
| 12 | University management | See a coherent public face and data quality | No single view | — | Prototype with provenance labels on every record; audit documents | Implemented (demonstration) |
