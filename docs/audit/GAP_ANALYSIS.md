# Gap Analysis

Compares what the master brief requires with what was observed on the public estate (2026-11-11). "Observed" means seen in fetched content; "Not observed" may mean absent or simply not reached by this partial audit.

| Module | Current state (evidence) | Gap | Prototype response |
|---|---|---|---|
| A Homepage | Exists; news stale, undated (S02) | Audience routing, programme search, fresh dated news | New homepage with audience paths and programme search |
| B About | Rich page tree; some pages 2023 (S04, S09, S11) | Facts & figures only in PDF | About page using verified facts with sources |
| C Programmes | Flat list, no detail pages, no filters (S06) | Searchable catalogue | Catalogue with faculty/level/campus filters on verified names; descriptions marked demo |
| D Admissions | One page with tabs; inconsistent naming (S08) | Distinct pathways | Pathway cards linking to official systems |
| E Unit sites | ~110 separate sites (S05) | Shared template with delegated editing | Faculty template driven by data |
| F Research | RMC, Science Park, AI Hub separate (S24, S25, S28) | Searchable researcher/project directory | Directory with clearly marked demo records only |
| G International | i-PUTRA homepage stale (2019); Visa page empty (S14, S19) | Up-to-date, dated guidance | Hub with "content needed from owner" notices instead of invented visa rules |
| H Campus life | HEP, BPP, library, colleges separate (S29–S31) | One hub | Campus life hub and interactive map (demo coordinates) |
| I Student services | Links scattered (S04, S30) | Organised gateway | Gateway of real public links, no login |
| J Staff services | Links scattered (S04, S26) | Organised gateway | Gateway of real public links, no login |
| K Alumni | Separate site (S22) | Integration with central | Linked from Alumni & Partners nav |
| L News & events | Many archives, often undated | Single filtered archive | Filterable news/events using demo items |
| M Contact | Thin, no map (S12) | Searchable directory, enquiry form | Directory from verified contacts; validated form that does not send |
| Search | Not observed on fetched pages | Unified search | Client-side search across all local content |
| Bilingual | `?LANG=` toggle, mixed content (S08, S17) | Locale routing and lang markup | `/en` and `/ms` routes with `lang` set |
