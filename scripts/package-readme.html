Independent Concept Prototype: not an official UPM website. Built to evaluate a website redesign. Content marked "Demonstration" is not real.

UPM Digital Campus

Start here

This package contains the complete working prototype: 17 page types in English and Bahasa Malaysia (about 280 pages), as plain HTML, CSS and JavaScript in the site folder. It contains no programs to install or run, no server code, no database and no tracking.

Three ways to view it

A. No installation (recommended)
  1. Go to app.netlify.com/drop (a free static host).
  2. Drag the site folder onto the page.
  3. Open the address it gives you. The security headers in site/_headers are applied automatically.

Cloudflare Pages and GitHub Pages work the same way. Use a demonstration account, not a university production domain.

B. On a computer with Node.js

Open a terminal in this folder and run npx serve site, then open http://localhost:3000.

C. On a computer with Python 3

Run python3 -m http.server 8080 -d site, then open http://localhost:8080/en/.

Opening the HTML files directly from the folder (file://) is not supported: browsers block the scripts the interactive features need.

What to try

  • Homepage hero search: type "engineering" with Programmes selected.
  • Programme finder: filter 99 programmes by level, faculty, field, campus and mode. The address updates so a search can be shared.
  • Faculty directory on the homepage: search "forest", or choose Bintulu.
  • Student and staff service gateways: 28 links to UPM's existing systems, with insecure (http://) links flagged.
  • Contact form: submit it empty to see accessible error handling. It never sends anything.
  • Campus map, news archive, central search and the EN/BM switch.

What is real and what is not

  • Programme names, faculties, contacts, service links and history come from UPM's public pages, each with a source ID and check date.
  • Researchers, most news items and the map layout are demonstration content and are labelled.
  • All images are original temporary artwork, labelled as such, until licensed UPM photography is approved. The UPM logo is not used.
  • Interface text is bilingual; the homepage body is a Malay draft that needs review; other page bodies are English for now.

Security of this package

  • Static files only: nothing executes on a server, there is no login, and no personal data is collected or stored.
  • Security headers for the host are included (site/_headers, site/serve.json): Content Security Policy, HSTS, no framing, no MIME sniffing, strict referrer, no camera, microphone or location.
  • Every page is set to "noindex" so search engines will not list it.
