# Demo Script (about 10 minutes)

Start at `/en`. Point out the prototype notice at the top: this is not an official UPM site.

1. **Homepage** — audience cards ("I am…"), ways to apply, faculties, verified facts with source IDs, news with "Demonstration content" badges.
2. **Programme search** — type "engineering" in the hero search. Choose *Faculty of Engineering*, then *Undergraduate*; note the address bar updates. Type "aerospace" → 1 result. Open it.
3. **Programme detail** — key facts are verified; description, entry requirements and fees are intentionally empty with an explanation. "See application routes" jumps to the right pathway.
4. **Empty state** — on the catalogue, search "zzzz", then "Clear all filters".
5. **Search** — header search "library": results across places, services, contacts; filter by *Place*.
6. **Student / staff services** — real system links grouped by task, with "requires login" and "insecure http link" badges taken from the audit.
7. **International** — the visa section openly states that UPM's Visa & Pass page was empty (audit finding) rather than inventing guidance.
8. **Campus map** — select places from the list or markers; note the schematic disclaimer.
9. **Contact** — submit the empty form: focusable error summary; then complete it: routed to the right office, nothing sent.
10. **Bahasa Malaysia** — click "Bahasa Malaysia" in the top bar; interface switches, page stays the same; English body content is flagged.
11. **Mobile** — narrow the window: menu button, Escape closes it.
12. Close with `docs/BLUEPRINT.md` sections 9 and 10 (estimate, permissions needed).
